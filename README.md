## A multicomponent computational framework for representing conversational dynamics

## Overview

**CoDy** is a Streamlit-based research framework for representing and analyzing conversation as a **continuous, evolving multicomponent system**.

Rather than treating conversation as a sequence of isolated utterances, or assuming that conversational change can be captured by a single transition score, CoDy keeps several computational observables separate and examines how they evolve and interact over time.

The current implementation represents the primary computational state as:

$$
\mathbf{z}_t = (S_t,R_t,d_t,\kappa_t,u_t)
$$

where:

- **$S_t$** — contextual discontinuity
- **$R_t$** — structural instability / low persistence
- **$d_t$** — local angular displacement in embedding space
- **$\kappa_t$** — turning-angle curvature of the embedding trajectory
- **$u_t$** — local semantic dispersion

The five coordinates are deliberately retained as separate observables. The current framework does **not** use a Geometry Driver, event classifier, transition-pressure score, or informational-time variable in its primary implementation.

CoDy currently analyzes:

- the five continuous state coordinates,
- turn-to-turn changes in each coordinate,
- raw multivariate movement,
- variability-adjusted multivariate movement,
- the relative contribution of each coordinate to movement,
- compositional reorganization of movement,
- time-varying coupling among component changes,
- changes in the full rolling dependency structure,
- contextual and structural continuity,
- and participant-specific coherence trajectories.

Human-perceived conversational boundaries remain an **external validation target** rather than being generated by the application itself.

# 🧩 Computational Architecture

The current framework combines contextual, structural, and geometric descriptions of the same conversation.

| Component | Main role |
| --- | --- |
| **Embeddings** | Represent each turn in a semantic vector space |
| **IC–II / $C_t$** | Estimate contextual continuity over time |
| **$C_{\mathrm{inv}}$** | Estimate persistence of rolling graph organization |
| **$S_t$** | Contextual discontinuity: $1-C_t$ |
| **$R_t$** | Structural instability: $1-C_{\mathrm{inv}}$ |
| **IC–III / $d_t$** | Local angular displacement |
| **IC–III / $\kappa_t$** | Turning-angle curvature |
| **$u_t$** | Local semantic dispersion: $1-\rho_t$ |
| **First differences** | Directional turn-to-turn change in each coordinate |
| **$J_t$** | Raw normalized magnitude of complete-state movement |
| **$v_{\mathrm{rel},t}$** | Variability-adjusted multivariate movement |
| **Relative shares** | Distribution of adjusted movement across the five coordinates |
| **$CR_t$** | Reorganization of the relative movement composition |
| **Dynamic coupling** | Rolling correlations among component changes |
| **$Q_t$** | Change in the complete rolling dependency structure |
| **$C_i$** | Participant-specific coherence trajectories |

The central methodological choice is to keep the primary coordinates separate rather than assuming in advance that they belong in one scalar transition variable.

# 🔎 Semantic Representation

Each conversational turn is first mapped to a semantic representation.

The current interface supports:

- **MiniLM / SBERT**
- **E5**
- **BGE**
- **INSTRUCTOR**
- **TF-IDF** as an explicit baseline representation

The canonical MiniLM pathway uses `sentence-transformers/all-MiniLM-L6-v2` through Hugging Face Transformers with mean pooling and L2 normalization.

Alternative embedding backends can be selected in Explore mode. The application does not silently switch to another representation if the requested backend fails.

All downstream embedding-derived observables should be interpreted relative to the chosen representation model.

# 🔹 IC–II — Contextual Continuity

## $C_t$ — contextual continuity

CoDy models contextual continuity as a temporally evolving trajectory rather than as a static pairwise similarity score.

At each turn, the current utterance embedding is evaluated relative to an evolving contextual representation containing both:

- longer-term conversational memory,
- and recent local context.

The current IC–II implementation combines:

- semantic resonance,
- local displacement,
- temporal persistence,
- and a recovery term.

The result is:

$$
C_t \in [0,1]
$$

Interpretation:

- **higher $C_t$** → stronger continuity with the evolving conversational context
- **lower $C_t$** → greater contextual divergence

$C_t$ is an operational computational measure. It should not be interpreted as a direct psychological measurement of coherence.

---

# 🔹 $S_t$ — Contextual Discontinuity

The first coordinate of the primary state is:

$$
S_t = 1-C_t
$$

Therefore:

- **low $S_t$** → stronger contextual continuity
- **high $S_t$** → greater contextual discontinuity

$S_t$ is a continuous state coordinate, not an event category or transition probability.

Directional change is represented by:

$$
\Delta S_t = S_t-S_{t-1}
$$

---

# 🔹 Structural Persistence — $C_{\mathrm{inv}}$

CoDy characterizes local conversational organization through rolling similarity graphs.

Within each valid rolling window:

1. turns are represented as nodes,
2. cosine similarity defines weighted relations,
3. the graph is sparsified using k-nearest-neighbour connectivity,
4. a normalized graph Laplacian is constructed,
5. spectral features and weighted-degree statistics summarize graph organization.

This produces a structural feature vector:

$$
\Pi(G_t)
$$

CoDy compares consecutive graph summaries and converts their distance into:

$$
C_{\mathrm{inv}}(t)
$$

Interpretation:

- **high $C_{\mathrm{inv}}$** → relatively persistent rolling graph organization
- **low $C_{\mathrm{inv}}$** → stronger structural change

$C_{\mathrm{inv}}$ is not semantically independent: its graph is built from embedding similarities. Its role is to provide a relational and structural description that differs from direct contextual continuity.

Because two consecutive complete graph summaries are required, early turns remain undefined until sufficient structural context is available.

For a rolling graph window of size $W$, the first finite value can appear at zero-indexed turn:

$$
t=W
$$

---

# 🔹 $R_t$ — Structural Instability

The second primary coordinate is:

$$
R_t = 1-C_{\mathrm{inv}}(t)
$$

Therefore:

- **low $R_t$** → relatively persistent local graph organization
- **high $R_t$** → greater structural instability / lower persistence

As with $S_t$, $R_t$ is a state level rather than an event label.

Directional structural change is represented by:

$$
\Delta R_t = R_t-R_{t-1}
$$

---

# 🔹 IC–III — Geometric Conversational Dynamics

The IC–III layer treats the sequence of turn embeddings as a trajectory through representation space.

The current geometric observables are kept separate:

$$
d_t,\qquad \kappa_t,\qquad u_t
$$

No scalar Geometry Driver is used in the current application.

---

## Local angular displacement — $d_t$

Let $E_t$ and $E_{t-1}$ be consecutive unit-normalized turn embeddings.

CoDy computes:

$$
d_t = \frac{\arccos\left(E_t\cdot E_{t-1}\right)}{\pi}
$$

or equivalently before unit normalization:

$$
d_t =\frac{\arccos\left(\frac{E_t\cdot E_{t-1}}{\|E_t\|\|E_{t-1}\|}\right)}{\pi}
$$

with:

$$
d_t\in[0,1]
$$

Interpretation:

- **$d_t\approx0$** → consecutive embeddings point in very similar directions
- **larger $d_t$** → stronger local angular displacement
- **$d_t=1$** → maximally opposite directions in the normalized representation space

Angular displacement is a monotonic re-expression of cosine similarity as an angle-based distance-like quantity.

---

## Turning-angle curvature — $\kappa_t$

Local displacement does not describe whether the embedding trajectory itself changes direction.

Define consecutive displacement vectors:

$$
v_{t-1}=E_{t-1}-E_{t-2}
$$

and:

$$
v_t=E_t-E_{t-1}
$$

CoDy computes:

$$
\kappa_t =\frac{\arccos\left(\frac{v_{t-1}\cdot v_t}{\|v_{t-1}\|\|v_t\|}\right)}{\pi}
$$

with:

$$
\kappa_t\in[0,1]
$$

Interpretation:

- **low $\kappa_t$** → the trajectory continues in a relatively similar direction
- **high $\kappa_t$** → the trajectory makes a stronger local turn

$\kappa_t$ is a discrete turning-angle measure in the chosen embedding space. It should not be interpreted as literal differential-geometric curvature of an underlying psychological or semantic manifold.

---

# 🔹 Local Semantic Compactness and Dispersion

CoDy computes a local semantic compactness quantity:

$$
\rho_t\in[0,1]
$$

using a trailing local window in embedding space.

The fifth primary coordinate is then:

$$
u_t = 1-\rho_t
$$

Therefore:

- **low $u_t$** → locally compact semantic organization
- **high $u_t$** → greater local semantic dispersion

Using $u_t$ aligns its direction with the other primary coordinates: larger values correspond to greater discontinuity, instability, displacement, turning, or dispersion.

---

# 🔷 Primary Five-Dimensional State

The primary computational representation is:

$$
\boxed{\mathbf{z}_t=\left(S_t,R_t,d_t,\kappa_t,u_t\right)}
$$

The five coordinates are intentionally **not collapsed into a single transition score**.

This allows CoDy to inspect whether conversational change is associated with:

- one coordinate,
- several coordinates acting together,
- characteristic dissociations,
- recurrent temporal sequences,
- redistribution of relative movement contributions,
- changes in coupling among dimensions,
- or changes in the broader multivariate dependency structure.

The framework therefore does not assume that all dimensions should rise together.

A conversational change may, for example, involve:

$$
d_t\uparrow,\qquad \kappa_t\uparrow
$$

without a comparable rise in $R_t$, or may involve structural instability with relatively little local angular displacement.

Such dissociations are treated as potentially informative rather than as failures of a composite score.

---

# 🔷 First Differences

Turn-to-turn changes are computed separately for all five primary coordinates:

$$
\Delta S_t=S_t-S_{t-1}
$$

$$
\Delta R_t=R_t-R_{t-1}
$$

$$
\Delta d_t=d_t-d_{t-1}
$$

$$
\Delta \kappa_t=\kappa_t-\kappa_{t-1}
$$

$$
\Delta u_t=u_t-u_{t-1}
$$

A difference is defined only when both consecutive observations are finite.

These signals describe **directional movement** along each coordinate.

---

# 🔷 Raw Multivariate Movement Magnitude — $J_t$

CoDy computes a secondary summary of total one-turn movement in the complete five-dimensional state:

$$
J_t=\frac{\sqrt{(\Delta S_t)^2+(\Delta R_t)^2+(\Delta d_t)^2+(\Delta \kappa_t)^2+(\Delta u_t)^2}}{\sqrt{5}}
$$

Since the primary coordinates are bounded to $[0,1]$, division by $\sqrt{5}$ provides a normalized raw movement magnitude.

Interpretation:

- **$J_t\approx0$** → little complete-state movement
- **larger $J_t$** → stronger raw multivariate movement

$J_t$ is a **secondary descriptive quantity**, not a transition detector.

Equal numerical scaling does not establish equal reliability, equal psychological meaning, or membership in a single latent construct.

---

# 🔷 Variability-Adjusted Multivariate Movement — $v_{\mathrm{rel},t}$

Raw first differences can have different empirical variability across coordinates. A naturally volatile coordinate can therefore dominate a Euclidean movement measure even when its change is not unusual relative to its own baseline dynamics.

CoDy addresses this by scaling each coordinate change by a robust within-dialogue variability estimate:

$$
r_{S,t}=\frac{\Delta S_t}{s_S}
$$

$$
r_{R,t}=\frac{\Delta R_t}{s_R}
$$

$$
r_{d,t}=\frac{\Delta d_t}{s_d}
$$

$$
r_{\kappa,t}=\frac{\Delta \kappa_t}{s_\kappa}
$$

$$
r_{u,t}=\frac{\Delta u_t}{s_u}
$$

where $s_j$ is the corresponding robust change scale.

The primary estimate is:

$$
s_j = 1.4826\times\mathrm{MAD}(\Delta z_j)
$$

computed on the common set of fully observed five-dimensional steps.

If the MAD collapses numerically, CoDy falls back to RMS about zero. A completely flat coordinate receives scale $1$, leaving its standardized changes at zero.

The variability-adjusted movement vector is:

$$
\mathbf{r}_t=\left(r_{S,t},r_{R,t},r_{d,t},r_{\kappa,t},r_{u,t}\right)
$$

and total variability-adjusted movement is:

$$
v_{\mathrm{rel},t}=\sqrt{\frac{1}{5}\sum_j r_{j,t}^2}
$$

or equivalently:

$$
v_{\mathrm{rel},t}=\sqrt{\frac{r_{S,t}^2+r_{R,t}^2+r_{d,t}^2+r_{\kappa,t}^2+r_{u,t}^2}{5}}
$$

Interpretation:

- **small $v_{\mathrm{rel},t}$** → relatively little multivariate movement after accounting for ordinary coordinate-specific variability
- **large $v_{\mathrm{rel},t}$** → stronger movement relative to those variability scales

$v_{\mathrm{rel},t}$ answers **how much adjusted multivariate movement occurred**.

Because its scaling uses the full valid dialogue, it is a retrospective/offline descriptor rather than an online causal detector.

---

# 🔷 Composition of Variability-Adjusted Movement

For each valid non-zero adjusted step, CoDy computes the relative contribution of each coordinate:

$$
p_{j,t}=\frac{r_{j,t}^2}{\sum_k r_{k,t}^2}
$$

for:

$$
j\in\{S,R,d,\kappa,u\}
$$

The movement composition is therefore:

$$
\mathbf{p}_t=\left(p_{S,t},p_{R,t},p_{d,t},p_{\kappa,t},p_{u,t}\right)
$$

with:

$$
\sum_jp_{j,t}=1
$$

The composition is defined only when the complete five-dimensional adjusted step is valid and non-zero.

Whereas $v_{\mathrm{rel},t}$ describes **movement magnitude**, $\mathbf{p}_t$ describes **movement composition**.

Two turns can therefore have similar $v_{\mathrm{rel},t}$ values while being driven by very different combinations of coordinates.

The main CoDy trajectory exposes these relative shares directly in the turn-level hover information.

---

# 🔷 Contribution Reconfiguration — $CR_t$

CoDy compares consecutive variability-adjusted movement compositions using Total Variation distance.

The application exposes this as **Contribution Reconfiguration**:

$$
CR_t=\frac{1}{2}\sum_j\left|p_{j,t}-p_{j,t-1}\right|
$$

with:

$$
CR_t\in[0,1]
$$

Interpretation:

- **$CR_t=0$** → the relative composition of movement is unchanged from the previous valid step
- **higher $CR_t$** → stronger redistribution of which coordinates account for the movement
- **values near $1$** → near-maximal compositional redistribution

$CR_t$ should be interpreted separately from $v_{\mathrm{rel},t}$:

$$
\boxed{\text{movement magnitude}\neq\text{movement composition}}
$$

The current framework therefore distinguishes between **how much** the multivariate state changes and **how the internal organization of that change is redistributed**.

---

# 🔷 Raw Movement Shares and Direction

For every valid non-zero raw step, CoDy also computes raw squared-change contribution shares:

$$
C_j(t)=\frac{(\Delta z_{j,t})^2}{\sum_k(\Delta z_{k,t})^2}
$$

for:

$$
j\in\{S,R,d,\kappa,u\}
$$

and the normalized raw movement direction:

$$
\widehat{\Delta\mathbf{z}}_t=\frac{\Delta\mathbf{z}_t}{\|\Delta\mathbf{z}_t\|_2}
$$

These are descriptive quantities. The current primary composition view uses the variability-adjusted shares $\mathbf{p}_t$ rather than the raw shares.

In the main trajectory hover, arrows indicate whether each primary component increased, decreased, or remained approximately unchanged at the selected turn.

---

# 🔷 Dynamic Coupling

With five primary coordinates, there are:

$$
\binom{5}{2}=10
$$

pairwise relationships.

CoDy computes trailing-window Pearson correlations among both:

- state levels,
- and first differences.

The current interface visualizes coupling among the first differences, for example:

$$
r(\Delta S,\Delta R)
$$

$$
r(\Delta S,\Delta d)
$$

$$
r(\Delta d,\Delta\kappa)
$$

$$
r(\Delta\kappa,\Delta u)
$$

Interpretation within a trailing window:

- **$r>0$** → the pair tends to move in the same direction
- **$r<0$** → the pair tends to move in opposing directions
- **$r\approx0$** → little local linear association

These correlations are descriptive and do not imply causal coupling.

The rolling dependency window is configurable in Explore mode.

---

# 🔷 Dependency-Structure Reorganization — $Q_t$

The ten pairwise rolling correlations define the off-diagonal structure of a local $5\times5$ correlation matrix.

CoDy measures how much this dependency structure changes between adjacent turns using:

$$
Q_t=\frac{\sqrt{2\sum_{i \lt j}\left(r_{ij}(t)-r_{ij}(t-1)\right)^2}}{\sqrt{80}}
$$

Interpretation:

- **$Q_t\approx0$** → little change in the local dependency structure
- **larger $Q_t$** → stronger reorganization of relationships among the five coordinates

$Q_t$ is a **second-order exploratory descriptor**.

It is available as an optional plot inside the Dynamic Coupling view and should not be interpreted as a primary transition metric or event probability.

---

# 🔹 Participant-Specific Coherence — $C_i$

CoDy computes participant-specific coherence trajectories.

For each participant, the framework tracks how that participant's contributions align with an evolving conversational context while applying configurable temporal inertia.

These trajectories are exported as columns such as:

```text
Ci_A
Ci_B
Ci_C
```

They can support exploratory analysis of participant-specific continuity, divergence, and alignment patterns.

$C_i$ remains a computational description rather than a direct psychological measurement of participant state.

# 🖥️ Interface Structure

The current sidebar is organized into four tabs:

## Data

- load the built-in demonstration dialogue,
- or upload a `.csv` / `.xlsx` dialogue.

## Core

- select the semantic representation,
- choose the smoothing method,
- configure EMA / EWMA parameters in Explore mode,
- optionally provide a custom model name.

## Structure

- enable or disable $C_{\mathrm{inv}}$,
- configure graph window size,
- configure k-NN connectivity,
- configure the graph edge threshold,
- configure the number of spectral eigenfeatures.

## Visual

- configure participant-specific $C_i$ settings,
- choose whether to overlay $C_{\mathrm{inv}}$ on the main trajectory,
- configure the rolling dependency window for multicomponent coupling.

The application no longer includes an internal robustness-testing tab, event-classification tab, Geometry Driver, or informational-time view. Those forms of validation are better treated as external analysis workflows when required.

# 🔬 Research Positioning

The current framework does **not** define conversational transitions through an internal categorical event detector.

Instead, CoDy produces continuous computational trajectories that can later be compared with independently obtained evidence such as:

- human boundary annotations,
- discourse-analytic judgments,
- experimental manipulations,
- external behavioral measures,
- or separately executed robustness and replication analyses.

This separation is intentional:

$$
\boxed{\text{computational representation}\neq\text{external validation}}
$$

Human consensus should therefore remain independent of the computational signals when CoDy is evaluated against human-perceived conversational boundaries.

The framework is designed to make multivariate conversational organization measurable before deciding which patterns, if any, reliably correspond to human-perceived transitions.

# 🧠 Conceptual Position

The current computational progression is:

```text
utterances
→ semantic representations
→ contextual continuity C_t
→ structural persistence C_inv
→ geometric observables d_t, κ_t, ρ_t
→ primary state z_t = (S_t, R_t, d_t, κ_t, u_t)
→ component-wise first differences Δz_t
→ raw movement J_t
→ variability-adjusted movement v_rel,t
→ movement composition p_t
→ contribution reconfiguration CR_t
→ dynamic coupling and Q_t
→ external empirical validation
```

A central methodological principle is:

> **Measure candidate dimensions first; establish their empirical relationships second; construct stronger composite interpretations only if the evidence justifies doing so.**

A second principle is:

> **The magnitude of multivariate change and the organization of multivariate change should be treated as distinct computational properties.**

This differs from assuming in advance that every conversational transition should correspond to one high scalar score.

# ⚠️ Scientific Status and Limitations

CoDy is an evolving research framework.

Current limitations include:

- $S_t$, $R_t$, $d_t$, $\kappa_t$, and $u_t$ are computational operationalizations rather than established psychological constructs.
- All embedding-derived channels depend on the chosen representation model.
- $S_t$ and $R_t$ are best interpreted as offline within-dialogue descriptors in the current implementation because $C_t$ and $C_{\mathrm{inv}}$ use dialogue-level scaling.
- The current $d_t$, $\kappa_t$, and $u_t$ implementations are temporally causal.
- $C_{\mathrm{inv}}$ cannot be estimated until sufficient rolling structural context is available.
- The five coordinates may have different intrinsic temporal response properties.
- $J_t$ is a descriptive movement magnitude, not evidence that the five coordinates form one latent variable.
- $v_{\mathrm{rel},t}$ uses dialogue-level robust variability calibration and is therefore retrospective.
- $\mathbf{p}_t$ is a relative composition; its components necessarily sum to $1$.
- Because movement shares are compositional, an increase in one component's relative contribution mechanically affects the shares of the others.
- $CR_t$ measures compositional redistribution, not absolute movement magnitude.
- Rolling correlations can be unstable in short windows.
- Correlation among dimensions does not establish causal interaction.
- $Q_t$ is a second-order exploratory descriptor.
- Participant trajectories are computational summaries rather than validated psychological measurements.
- Agreement between computational patterns and human judgments must be established externally.
- Robustness across embeddings, parameter settings, datasets, annotation schemes, or null models should be evaluated outside the main application when required.
- Human transition judgments are themselves temporally uncertain and should not be treated as perfectly precise ground truth.
- Stronger theoretical claims require independent replication under a protocol fixed before examining replication outcomes.

The purpose of the framework is not to assume that a particular theory of conversational dynamics is correct.

Its purpose is to make candidate computational structures:

**measurable, inspectable, falsifiable, comparable, and empirically testable.**
